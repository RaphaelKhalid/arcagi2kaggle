02 / Main findings

What survived

01

Optimize output positions

Score is output-position based: maximize unresolved mass × novelty × selector recovery ÷ cost.

02

Exact fit is not proof

Use the version space, typed effects, counterexamples, and MDL before promotion.

03

Specialists should propose

Object graphs, cellular rules, scene graphs, and evolutionary search add narrow recall; none replaces the neural baseline.

04

Track correlation

Preserve provenance; collapse duplicate semantic outputs and credit independent lineages.

05

Shape is the safe gate

The paranoid cap fired correctly on 882/882 training and 109/109 evaluation cases; palette hard masks failed cross-fold soundness.

06

Long grids need a frontier

A fixed likelihood threshold collapses at length 400–900; use absolute or calibrated length-normalized evidence.

07

The controller is learned too
